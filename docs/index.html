Personal project · An agent harness for Palantir Foundry

Work in Foundry from the terminal, with your own agent.

Orthanc is an agent-native Foundry CLI. pi-palantir is a harness for the Pi coding agent that drives it. Mirdain is an experimental Mac app on top. ReasoningBank is how it learns.

01Install

Start with Orthanc. pi-palantir needs it on your PATH. Mirdain bundles its own harness.

Layer 1 · The CLIShipped · v0.2.1

Orthanc

Agent-native Foundry CLI, written in Rust. One JSON contract on every call, plan-first writes, and credentials kept out of arguments.

curl -fsSL https://github.com/zaycruz/orthanc/releases/latest/download/install.sh | sh

macOS (Apple silicon and Intel) and Linux x86_64. SHA-256 verified. No GitHub account needed.

Layer 2 · The harnessShipped · 0.4.0

pi-palantir

A harness for the Pi coding agent, built for Palantir: scope and context every turn, an approval ladder, a branch gate, a Jev risk judge, a loop guard, and subagents.

  • New configure profile create command: create a named profile with an interactive host prompt and a hidden token prompt, or pass them non-interactively. The token is stored in the macOS Keychain.

pi-palantir

Layer 2
0.4.02026-09-21
  • New approval ladder replaces work roles. Pick a mode with /approval: ask-always, allow-edits, auto (the default), or yolo. The /role command is removed.
  • Guarded actions open an approval prompt instead of being blocked with no way forward. Destructive actions always ask, in every mode.
  • If the AI risk check is unavailable, the harness now asks for approval instead of letting the action through.
  • The Foundry MCP server is disconnected. All Foundry writes go through the Orthanc CLI.
  • MCP servers can declare themselves read-only in mcp.json, and tool-discovery calls are treated as reads.
  • Command risk levels now come from Orthanc's own manifest, so read-only commands are no longer blocked as if they were writes.

Mirdain

Layer 3
v0.0.22026-09-12
  • Compact, expandable subagent activity shows assignments, current work, and reported progress while you keep chatting.
  • Saved workflows with AI-assisted drafting, editable steps, slash-command launch, and local scheduled automations. Both are opt-in.
  • Harness slash commands stay available next to workflows. Workflows use their own prefix when names collide.
  • Settings, tabs, workflow drafts, and sessions are saved more reliably, including when you quit.
  • Nightly builds keep their own app data and credentials, separate from the stable app.
  • Signed with Developer ID and notarized by Apple. Requires Apple silicon and macOS 26 or later.
