L1Orthanc

Release assets on GitHub

UnreleasedUnreleased
  • Agent output keeps ontology API names (for example property API names) exactly as the platform returns them instead of rewriting them.
  • New repository tag commands: create and list tags, and read a repository's fallback branches.
  • Updated the TLS library to address a published security advisory.
v0.2.12026-09-20
  • New configure profile create command: create a named profile with an interactive host prompt and a hidden token prompt, or pass them non-interactively. The token is stored in the macOS Keychain.
v0.2.02026-09-17
  • Guided orthanc onboarding sets up your first profile, stores the token in the Keychain, and makes it active. The installer runs it for new installs only and skips it on updates.
  • Nightly release channel that installs beside the stable version.
  • Stricter agent mode: one JSON envelope for every result, including argument errors, consistent exit codes, confirmation prompts that fail safely in agent sessions, and wider secret redaction.
  • New commands: run commands in and proxy to repository containers, preview transforms and TypeScript functions, create eval suites and compute modules, and read or update solution designs.
  • Built-in orthanc smoke self-check with an optional daily schedule on macOS. Search now also returns ontology object types and link types.
v0.1.22026-09-14
  • One-line install.sh installer that does not need a GitHub login.
  • The installer rejects downloads that fail checksum verification.
  • Releases are published only after binaries for every supported platform are present.
v0.1.02026-09-14
  • First release of Orthanc, a fast Rust CLI for Palantir Foundry, built to be used by AI agents as well as people.
  • Covers all 246 commands of the Python reference CLI, with 298 native command paths in total.
  • Works across datasets, ontology, SQL, builds and schedules, repositories, functions, streams, models, and admin.
  • --agent mode returns one structured JSON envelope per command, and agent-manifest lists every command with its risk level.
  • Safe changes by default: dry-run plans before mutations, and destructive operations need an explicit flag.
  • Prebuilt binaries for macOS (Apple silicon and Intel) and Linux x86_64. Credentials come from the macOS Keychain, environment variables, or named profiles.

L2pi-palantir

Recent releases.

0.4.02026-09-21
  • New approval ladder replaces work roles. Pick a mode with /approval: ask-always, allow-edits, auto (the default), or yolo. The /role command is removed.
  • Guarded actions open an approval prompt instead of being blocked with no way forward. Destructive actions always ask, in every mode.
  • If the AI risk check is unavailable, the harness now asks for approval instead of letting the action through.
  • The Foundry MCP server is disconnected. All Foundry writes go through the Orthanc CLI.
  • MCP servers can declare themselves read-only in mcp.json, and tool-discovery calls are treated as reads.
  • Command risk levels now come from Orthanc's own manifest, so read-only commands are no longer blocked as if they were writes.
0.3.42026-09-20
  • Agents can clone Foundry repositories locally through Orthanc. The harness tracks each clone and shows it in the agent's context.
  • Cloning no longer needs a working branch first, and creating a branch in a session now correctly unlocks branch-scoped changes.
0.3.32026-09-20
  • Reads Foundry credentials saved by orthanc onboarding and orthanc auth store, with a fallback to older profiles. This fixes startup failures on fresh installs.
0.3.22026-09-20
  • Orthanc-first: Orthanc is now the main Foundry CLI, used through orthanc_cli and orthanc_help with live usage hints and checks after each change. The launcher is renamed to pi-palantir.
  • Branch safety: changes must target a working branch, and writes to main branches or production ontologies are blocked.
  • AI pre-tool guard checks risky tool calls before they run.
  • Safer memory: only the harness can save lessons, after a quality check. Doubtful entries are held for review.
  • Lower token use: large tool results are capped, with --output to save the full result to a file, and a loop guard redirects agents that repeat the same call.
  • New native commands: cp, osdk context, and notepad create. link-type-list now finds incoming links.

L3Mirdain

Experimental.

v0.0.22026-09-12
  • Compact, expandable subagent activity shows assignments, current work, and reported progress while you keep chatting.
  • Saved workflows with AI-assisted drafting, editable steps, slash-command launch, and local scheduled automations. Both are opt-in.
  • Harness slash commands stay available next to workflows. Workflows use their own prefix when names collide.
  • Settings, tabs, workflow drafts, and sessions are saved more reliably, including when you quit.
  • Nightly builds keep their own app data and credentials, separate from the stable app.
  • Signed with Developer ID and notarized by Apple. Requires Apple silicon and macOS 26 or later.
v0.0.12026-09-12
  • Native macOS workspace for Pi Palantir. Each conversation tab runs its own agent process, context, and history.
  • Split panes, side by side or top and bottom, run independent conversations.
  • Open browser tabs next to agent conversations, and browse or search models by provider.
  • Workspaces, projects, conversations, drafts, and layout are kept when you reopen the app.
  • Self-contained download: includes Node, Pi Palantir, extensions, and local search tools. No Homebrew or Node install needed.
  • Signed with Developer ID and notarized by Apple. Requires Apple silicon and macOS 26 or later.
