ORT-04Changelog

Changelog

Assets and checksums for each release are on GitHub.

v0.7.32026-11-12
  • Breaking: repository build-logs reads every step of a job, not only step 0, and the per-step fields move under data.steps[]. Failed, canceled and aborted steps come first. --step N reads one step. Output is limited per step with --max-chars and in total with --max-total-chars; --full removes the limits.
  • New automate triggers: shows why an automation runs: its schedules with their time zone, the object-set events it watches, and its effects.
  • New automate run: shows what one run did: what triggered it, how many objects it saw, and the result of each effect, with the errors grouped by message.
  • automate status --history N now reads only the last N runs, so it no longer downloads a large page of history.
  • repository imports add --source and repository imports remove --source now work on a Python transforms repository that has no resources.json. The import covers every branch, so a non-default --branch is refused there.
  • Fixes: a lost reply to automate create or automate update is reported as an error after the write that is not retryable, so a retry does not make a duplicate. automate get no longer hides project-scoped effects, so its output goes back through automate update unchanged.
v0.7.22026-11-12
  • New repository push --repo-dir PATH: every Git call of the push runs in the named clone, so a push works from a tool that does not run inside the clone. A folder that is not a clone is a usage error before credentials are read.
  • --select is now optional on ontology object-get, ontology object-list and ontology object-search. Without it, every property comes back. A blank or padded value is refused before any request.
  • When repository push refuses because the remote is ahead, the rebase hint names the remote commit.
v0.7.12026-11-12
  • New marketplace group, the install side of Marketplace: read stores, products, versions, installations, install jobs and upgrade settings, for example marketplace product versions and marketplace installation get --entities.
  • Install lifecycle: marketplace installation create, upgrade and uninstall, and marketplace job cancel. These cannot be undone, so they need --apply --yes, and uninstall also needs --expect with the digest of the preview it prints. marketplace automation set and resume change automatic upgrades.
  • New devops group, the make side: devops store create, devops product create, devops draft get, set, publish and abort, devops version create and channel, and devops product deprecate and undeprecate.
  • Compute modules from your own image: artifacts repo create and artifacts docker push put a local image into Foundry, and the token never reaches argv, output or ~/.docker. compute configure sets a module's image, environment, sources, replicas, CPU and memory. All three print a plan first.
v0.7.02026-11-11
  • New pipeline group for Pipeline Builder on a global branch: pipeline get, create, edit, check, publish and deploy, plus sandboxes and versions.
  • New workshop module commands: list, get, widgets, create, update, publish and delete.
  • New automate group: automate list, get, status, create, update, pause, resume and delete. A create or update prints a plan that holds Foundry's validation.
  • Branches: global-branch list and reads of a branch's resources, versions, roles, markings and deployability; repository branch list and create; a new branch-protection group that reads and sets branch protection and required approvers; and repository pull-request approval, which shows what a pull request still needs.
  • Functions: functions execute runs a function by RID through the function executor and shows the edits an edit function would make. The function verbs and repository tag create take --branch to use the versions a global branch published. This part was tagged as 0.6.0, which had no published binaries.
  • Data: ontology semantic-search over a vector property, transforms preview for one Python transform, dataset create-from-csv, data-health check delete, pause and resume, data-health check groups and check types,media-sets input-schema add and remove, container data-scope, and docs platform-sdk list and get. container exec also takes the command as separate arguments.
v0.5.02026-10-23
  • New repository pull-request merge: merges a pull request (squash, no fast-forward, or fast-forward) only when Foundry reports it as mergeable. --apply needs --expect-head, so a branch that moved after review is refused.
  • New repository compare and repository branch-status: a commit-range diff with file changes and diff stats, the commit list, and the ahead and behind counts.
  • New repository branch delete: deletes a branch with a lease on its head, so a branch that moved since the plan is refused.
  • compute logs pages are bounded at 100, the Foundry maximum. Compute log pages and build log text are redacted, and the redactor finds more token shapes.
  • A dependency update for a published security advisory (RUSTSEC-2026-0385).
v0.4.12026-10-21
  • Breaking: ontology query-execute and functions query execute run a function that can change state, such as a webhook, an AIP agent or a compute module, only with --apply. Without it they print the run as a plan with the warning function-can-change-state. Query functions run as before.
  • Data Connection: connectivity import create-file, create-table, run and delete; connectivity source create-s3; connectivity source secret list and secret set, which reads the value from stdin only; and connectivity sync list, which reads the sync configs of every source type. connectivity egress ensure works again.
  • Files and projects: resource move moves datasets, repositories and other resources into a folder. project imports add and remove change a project's references, Spark profiles included. repository create-python-transforms --parent-rid makes the repository in that folder, and repository imports add --source now writes.
  • Datasets and lineage: dataset job-spec shows which repository, branch and file build a dataset. lineage graph --edges build,sync follows builds and syncs, and --details on job listings shows the input datasets. dataset schema set accepts the output of dataset schema get.
  • Ontology and functions: ontology summary counts types against the ontology's limits, and type creates warn before they pass one. Functions calls always send preview mode and show Foundry's message for a person in errors[].user_message. functions query execute-by-rid runs functions that an ontology binds. dev-console scope add and update send function pins with --apply, and dev-console scope get reads them.
  • Also in this release: the changes tagged as 0.4.0, which had no published binaries, and a TLS library update for published security advisories (RUSTSEC-2026-0381, RUSTSEC-2026-0382).
